# دستیار هوشمند ترمینال لینوکس (Linux Terminal Agent - LTA) 🐧⚡

پروژه‌ای ماژولار، امن و بهینه‌سازی شده برای اجرای دستورات لینوکس بر اساس پرامپت‌ها و درخواست‌های متنی (به زبان فارسی یا انگلیسی).

این ابزار با **صفر وابستگی خارجی اجباری** (تنها با کتابخانه استاندارد پایتون ۳) طراحی شده است تا هر کاربری بر روی هر توزیع لینوکسی (اوبونتو، دبیان، آرچ، فدورا، آلپاین و...) بتواند آن را بدون دردسر نصب و اجرا کند. همچنین معماری آن کاملاً ماژولار است و از هر دو حالت **آفلاین (Ollama، سرورهای محلی)** و **آنلاین (OpenAI، Groq، Claude، Gemini)** پشتیبانی می‌کند.

---

## 🌟 ویژگی‌های کلیدی

- 🔌 **پشتیبانی ماژولار از هوش مصنوعی (آفلاین و آنلاین)**:
  - **حالت کاملاً آفلاین و محلی (Private & Offline)**:
    - **Ollama**: اجرای مدل‌هایی مانند `qwen2.5-coder`، `llama3`، `deepseek-coder` به صورت ۱۰۰٪ آفلاین و بدون نیاز به اینترنت.
    - **سرورهای محلی سازگار با OpenAI**: اتصال به `llama.cpp`، `LM Studio`، `vLLM` یا `LocalAI`.
    - **موتور مبتنی بر قوانین (Rule-Based)**: حتی بدون نصب هیچ مدلی، صدها دستور پرکاربرد سیستم‌عامل را مستقیماً پردازش می‌کند.
  - **سرویس‌های ابری و آنلاین (Cloud AI)**:
    - **Groq**: با سرعت فوق‌العاده بالا و سهمیه رایگان.
    - **OpenAI**: مدل‌های GPT-4o و GPT-4o-mini.
    - **Anthropic Claude**: مدل‌های Claude 3.5 Sonnet و Haiku.
    - **Google Gemini**: مدل‌های سری Gemini Flash و Pro.
    - **OpenRouter**: دسترسی به صدها مدل متنوع با یک کلید API.
- 🛡️ **لایه امنیتی و گارد محافظ (Safety Guardrails)**:
  - تفکیک دستورات به سطوح `امن`، `احتیاط`، `خطرناک` و `مسدود شده`.
  - مسدودسازی همیشگی دستورات مخرب (مانند `rm -rf /`، بمب فورک، دستکاری سکتورهای خام دیسک، `chmod -R 777 /`).
  - امکان ویرایش دستور، تایید یا لغو آن قبل از اجرا.
- 🧠 **شناسایی خودکار محیط لینوکس (Context-Aware)**:
  - تشخیص توزیع لینوکس (Ubuntu, Debian, Arch, Fedora و...)
  - تشخیص پکیج منیجر پیش‌فرض (`apt`, `pacman`, `dnf`, `apk`)
  - شناسایی شل فعال (`bash`, `zsh`, `fish`)
  - شناسایی سطح دسترسی (`root` یا کاربر عادی با دسترسی `sudo`)
- 💬 **پشتیبانی کامل از زبان فارسی و انگلیسی**.
- 💻 **حالت تعاملی شبیه چت (Interactive REPL)** و حالت اجرای تک‌خطی.

## 📥 نصب آسان و سریع با یک دستور

اسکریپت نصب خودکار را اجرا کنید:

```bash
git clone https://github.com/nimajavan/linux-terminal-agent.git
cd linux-terminal-agent
chmod +x install.sh
./install.sh
```

این اسکریپت به صورت خودکار پایتون ۳ را بررسی کرده و دستور `lta` را در مسیر سیستم شما قرار می‌دهد.

برای حذف:
```bash
./uninstall.sh
```

## 🚀 راهنمای استفاده

### ۱. اجرای مستقیم دستورات (One-Shot)

```bash
# درخواست به زبان فارسی
lta "میزان فضای خالی دیسک و حافظه رم را نشان بده"

# جستجوی فایل‌های پرحجم
lta "فایل های بزرگتر از ۱۰۰ مگابایت را در پوشه فعلی پیدا کن"

# بستن پروسه روی یک پورت خاص
lta "پروسه ای که روی پورت ۸۰۸۰ در حال اجراست را ببند"

# اجرای مستقیم بدون نیاز به تایید مجدد (برای دستورات امن) با پرچم -y
lta -y "پورت های باز سیستم را نمایش بده"

# پیش‌نمایش بدون اجرا (Dry-Run) با پرچم -d
lta -d "نصب برنامه داکر"
```

### ۲. حالت تعاملی (Interactive REPL)
با نوشتن `lta` وارد محیط کنسول اختصاصی می‌شوید:
```bash
lta
```
سپس می‌توانید بدون خروج از محیط، انواع درخواست‌ها را مطرح کنید:
```text
lta (my-project) > وضعیت سرویس nginx را بررسی کن
lta (my-project) > آخرین کامیت های گیت را نمایش بده
lta (my-project) > history
lta (my-project) > exit
```

## ⚙️ پیکربندی هوش مصنوعی (آفلاین / آنلاین)

### روش اول: استفاده کاملاً آفلاین با Ollama (پیشنهادی برای امنیت و حریم خصوصی)
۱. نصب Ollama:
```bash
curl -fsSL https://ollama.com/install.sh | sh
```
۲. دانلود یک مدل بهینه‌شده برای کدنویسی و لینوکس:
```bash
ollama run qwen2.5-coder:7b
# یا:
ollama run deepseek-coder:6.7b
```
۳. تنظیم به عنوان ارائه‌دهنده پیش‌فرض:
```bash
lta config set provider ollama
lta config set model qwen2.5-coder:7b
```
۴. تست اتصال:
```bash
lta test ollama
```

### روش دوم: استفاده از سرورهای محلی (Local AI / llama.cpp / LM Studio)
اگر در سیستم خود یک سرور لوکال اجرا کرده‌اید:
```bash
lta config set provider local
lta config set local.endpoint "http://localhost:8080/v1"
```

### روش سوم: استفاده از هوش مصنوعی آنلاین (با API Key)
می‌توانید کلیدهای API را در محیط سیستم اکسپورت کنید یا از طریق دستور تنظیم نمایید:

- **استفاده از Groq (بسیار سریع با سهمیه رایگان مناسب)**:
  ```bash
  export GROQ_API_KEY="gsk_..."
  lta -p groq "لیست ۱۰ پردازش سنگین رم را نشان بده"
  ```
- **استفاده از OpenAI**:
  ```bash
  export OPENAI_API_KEY="sk-..."
  lta -p openai -m gpt-4o-mini "آرشیو zip فایل های دانلود را بساز"
  ```
- **استفاده از Anthropic Claude**:
  ```bash
  export ANTHROPIC_API_KEY="sk-ant-..."
  lta -p anthropic "لاگ های خطای سیستم را فیلتر کن"
  ```
- **استفاده از Google Gemini**:
  ```bash
  export GEMINI_API_KEY="AIzaSy..."
  lta -p gemini "آپدیت بسته‌های سیستم"
  ```

## 🔧 دستورات مدیریتی CLI

| دستور | کارکرد |
|---|---|
| `lta info` | نمایش اطلاعات توزیع لینوکس، پکیج منیجر و تنظیمات فعال ایجنت |
| `lta test [provider]` | تست سلامت و پاسخ‌دهی هوش مصنوعی انتخاب‌شده |
| `lta history` | مشاهده تاریخچه دستورات ترجمه شده و نتایج اجرای آن‌ها |
| `lta config list` | مشاهده فایل پیکربندی فعلی |
| `lta config set <key> <value>` | تغییر مقدار در تنظیمات (مثلاً `lta config set provider groq`) |
| `lta --help` | نمایش راهنمای کامل پرچم‌ها و سوئیچ‌ها |

## 🛡️ لایه امنیتی

برای جلوگیری از هرگونه تخریب اتفاقی سیستم:
1. **دستورات خطرناک مطلق (BLOCKED)**: دستوراتی نظیر `rm -rf /`، پاک کردن شاخه خانگی، فرمت مستقیم دیسک‌های فیزیکی، بازنویسی دیسک با `dd`، بمب فورک و تغییر پرمیشن ریشه به ۷۷۷ به هیچ عنوان اجرا نمی‌شوند.
2. **دستورات حساس (DANGEROUS)**: دستوراتی مانند `shutdown`، تغییرات فایروال یا بازنویسی پارتیشن‌ها همیشه حتی در صورت وجود پرچم `-y` اخطار مشخص می‌دهند و تایید مجدد می‌خواهند.
3. **دستورات احتیاطی (CAUTION)**: ری‌استارت کردن سرویس‌ها، توقف پروسه‌ها یا حذف بسته‌ها با برچسب زرد رنگ مشخص می‌شوند.
4. **دستورات امن (SAFE)**: دستورات فقط-خواندنی با برچسب سبز رنگ متمایز می‌شوند.
